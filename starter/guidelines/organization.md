# Organization and upkeep

Group notes by subject. Add nested directories when they make material easier to find. Keep supporting notes near the subject they explain. The vault README identifies the subject entry points.

These root guidelines apply throughout the vault. A scope can add its own `guidelines/`, read after the framework and root guidance. Nested scopes can add another layer.

Put a capture directly in its subject folder when it fits. Use `inbox/` when sorting can wait. During inbox review, fold useful material into an existing note or give it a home. An open question about renewing an editor can stay with the editor notes between renewals. Remove abandoned material when the task and the note's editing permission allow it.

The owner decides when inbox reviews happen. Record a recurring schedule here if one becomes useful.

Keep attachments in the configured attachment location. The starter's Obsidian settings use `attachments/`.
