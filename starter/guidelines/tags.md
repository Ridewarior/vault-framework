# Tags

These are starter choices for this vault. Add or change them as needed.

| Tag | Use |
| --- | --- |
| `resource` | Reference information |
| `research` | Questions, findings, and sources |
| `meeting` | Meeting notes |
| `decision` | A standing decision record |
| `decision/architecture` | An architectural standing decision record |
| `thought-bubbles` | Ideas still taking shape, wherever they are filed |

Subject tags can help with search. Define any tag that changes required fields or placement here before relying on that behavior.
