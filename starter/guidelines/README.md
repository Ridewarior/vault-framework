# This vault's guidelines

These rules describe how we document things in this vault. Edit them as its subjects and needs change.

- [Tags](tags.md) lists the tags used here.
- [Properties](properties.md) defines local fields and note status.
- [Organization](organization.md) explains where notes go and how to process the inbox.

These root guidelines apply throughout the vault. Add scoped `guidelines/` directories for subject-specific detail, following the framework and root guidance. Keep the framework copy in `vault-framework/` unchanged.
