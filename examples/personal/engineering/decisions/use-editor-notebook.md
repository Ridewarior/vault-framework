# Keep engineering notes in the editor's notebook

I chose the built-in notebook while I was doing all my engineering work in one editor. I could capture a finding without leaving the code I was reading.

When I started using a second editor, I [switched to Markdown](plain-text-storage.md) so I could search the same notes from either one.
