# Work-vault example

This optional example adds ticket documentation to the general starter. Its rules belong to the work vault that adopts them.

After [creating a vault](../../docs/setup.md), copy these additions into a fresh setup:

| Source here | Destination in the vault |
| --- | --- |
| `guidelines/` contents | The vault's `guidelines/` |
| `templates/` contents | The vault's `templates/` |
| `AGENTS.md` | Root agent instructions |
| `catalog/` | Optional fictional knowledge scope |

Review files before replacing rules in an existing vault. Keep `vault-framework/` unchanged. Edit the local rules for the actual tracker, subjects, and workflow.

The [local guidelines](guidelines/README.md) cover work-item notes, completion evidence, and execution plans. Work templates add the matching note shapes without making them part of the framework.
