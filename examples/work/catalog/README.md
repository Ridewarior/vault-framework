# Catalog

The catalog project repository holds its engineering rules and implementation. Look here in `decisions/` for any standing catalog choices recorded in the vault. The work notes under `work/` explain individual tickets.

For example, the [search feedback discussion](work/42-search-feedback/questions-and-decisions.md) explains why an empty search suggests another term and which question about errors remains open.
