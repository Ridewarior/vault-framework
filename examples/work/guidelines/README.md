# Work-vault guidelines

These sample rules extend a vault for engineering work. Adopt and edit them only where work-item tracking is useful.

| Document | Covers |
| --- | --- |
| [Organization](organization.md) | The sample catalog scope and ticket locations |
| [Tags](tags.md) | Work and supporting-note tags |
| [Properties](properties.md) | Ticket identifiers and note status |
| [Work items](work-items.md) | Main notes and companions |
| [Completion criteria](completion-criteria.md) | Outcomes and evidence |
| [Execution plans](execution-plans.md) | Task progress across sessions |

A vault's notes support its existing work tracker. Publishing or changing that tracker requires a user request.
