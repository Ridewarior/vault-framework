# Tags

This sample uses `work` for a tracked unit of work and `sub-doc` for a note that supports one.

| Tags | Use |
| --- | --- |
| `work/feature`, `work/bug`, `work/enhancement`, `work/docs` | Types of implementation work |
| `work/research` | A tracked research task |
| `sub-doc/decisions` | Questions and choices specific to the parent work item |
| `sub-doc/working-notes` | Investigation and implementation detail |
| `sub-doc/agent-tasks` | An execution checklist |
| `research` | Standalone findings rather than a tracked task |
| `resource` | Reference information |
| `decision`, `decision/architecture` | Standing decision records for a subject |
| `meeting` | Meeting notes |
| `thought-bubbles` | Ideas still taking shape in the inbox or a subject folder |

A companion uses its own tag rather than its parent's work tag. Use subject tags where they help with search and define any additional placement rules locally.
